# 从内容到模板的选用规则

## 先问表达目的

每页先完成一句话：“希望听众理解／接受……，为此提供……”。列出真实内容中的信息角色与关系，不把版式上的三个方框当作三个研究方向。

| 表达任务 | 首选关系 | 可检索原型 | 选择依据 |
|---|---|---|---|
| 多个同级方面 | 并列、总分 | T07、T34 | 模块地位相同，最好有共同说明维度 |
| 总目标及研究内容 | 总分、总—分—总 | T09、T33 | 是否有共同验证；阶段是否确实递进 |
| 介绍对象与局部 | 整体—部分、映射 | T03、T14、T15 | 局部位置能否直接对应整体图 |
| 背景演变与研究需求 | 时序、演化 | T02、T05 | 事件先后不等于因果 |
| 缺口与研究切入点 | 问题—解决 | T08、T10、T19、T38 | 同级问题、分层问题或流程失效点 |
| 数据或对象经过变换 | 输入—处理—输出 | T12 | 输入、处理机制、输出均可明确命名 |
| 多条路径共同产出 | 汇聚、流程 | T13、T36 | 每条路径对共同结果有清楚贡献 |
| 两个目标共同实现 | 并列目标、约束 | T41 | 双目标不自动构成对比或权衡 |
| 模型与对象对应 | 映射 | T11、T20、T31 | 能明确对应项及转换规则 |
| 方法或算法步骤 | 流程、反馈 | T24、T30 | 是否存在真实回传量及下一轮作用 |
| 系统组成与分工 | 层级、整体—部分 | T28、T37 | 区分架构层次与普通要素关联 |
| 证明实验结论 | 观点—证据、对比 | T16—T18、T21、T22、T25、T26 | 区分参数选择、消融、定量比较和效率评价 |
| 实物、软件或应用演示 | 主次、实例 | T29、T34、T35 | 截图只说明功能存在，不能替代效果评估 |
| 条件保障与成果展示 | 映射、总分 | T39、T40 | 写清资源能保障什么任务，以及成果统计口径 |

## 候选排序

先满足关系，再满足内容容量，最后比较风格。依次考虑：

1. 主关系是否相同；复合页面允许保留辅助关系。
2. 实际模块数、依赖方向、层级深度是否匹配。
3. 核心证据是文字、图、表还是界面；是否有合适的位置。
4. 是否能填满内容槽位；不为凑版式补写无根据的内容。
5. 是否需要小改、拆页或重新搭建。槽位不够时不以持续缩小文字解决。

检索脚本使用关系筛选和文字匹配返回候选。不要把分数称为逻辑正确率或美观评分。

## 页级规划格式

逐页策划采用 [汇报卡片规则](report-cards.md) 和 [卡片模板](../assets/slide-cards.md)。简单选页请求可只记录表达目标、主关系、结构表达、材料依据、模板ID和调整项。已经要求完整PPT时，用卡片指导制作，不额外强制等待审批。

## 典型边界

- “精度、效率、鲁棒性”常是三个评价维度，用并列；并不因为有三项就标为三个流程步骤。
- “传感数据、历史案例、物理约束共同得到决策”可以先检索汇聚，再根据是否有后续处理选择T13或T36。
- “三种输入依次处理并输出”需区分三路并行输入和三步串行处理；有歧义时先澄清机制。
- “输出再次测量并调整下一轮输入”才具备反馈路径；只画圆环不成立。
- 提供相同指标的多个方法用对比；方法的多种功能用并列。实验优势必须由真实证据支撑。
