# 模板备注与索引约定

版本：1.0。每页备注采用九行固定字段，优先保持约200—320个汉字以内。

```text
模板：TPL-N25｜多来源汇合与分步处理
原型：T13｜多路径汇合方法
关系：汇聚、流程
结构：3→1→1
适用：多源信息融合、联合处理
槽位：3类输入；处理步骤；输出与应用
注意：输入应共同参与处理，不能仅为三项独立成果。
分组：方法原理与技术路线
来源：N25｜022.png
```

字段含义：模板ID唯一且稳定；原型ID表示结构类别；关系为概括标签；结构使用抽象表达式；适用与槽位描述通用信息角色；注意指出最关键选用边界；分组为当前合集中的导航类别；来源保留案例ID与当前素材名。

P45、P46用“无原型／不适用”，不计入41类页面原型。备注不附长段原文、历史工作日志或绝对路径。

`catalog.json`是派生文件，包含模板当前页码、固定字段、原生形状／表格数量、命名图片区数量，以及PPTX的SHA-256。图片区数量是识别到的空白形状数量，可能包含Logo位；不直接代表需要提供的实验图数量。

维护方式：编辑PPT备注或新增／移动页面，保存PPT后运行：

```text
python scripts/template_catalog.py index --output assets/catalog.json --replace
python scripts/template_catalog.py validate
```

生成索引会检查重复ID及缺失字段。使用新版模板替换`assets/template-library.pptx`时，先保留旧版备份。不要同时手改备注和JSON。大幅调整版式应更新槽位、适用边界和原型归属；新增不同版式应分配新模板ID。
